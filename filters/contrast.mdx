## Overview

Contrast filters can sharpen visual separation in photos, badges, and overlays, but CSS `filter` is not currently mapped by the Skelementor importer and no bundled contrast utility classes are shipped in `skelementor-utilities.css`.

Use custom frontend CSS when contrast filtering is essential, and test carefully to avoid overly harsh imagery.

## Example

```css
.contrast-boost {
  filter: contrast(1.15);
}

.contrast-soft {
  filter: contrast(0.9);
}
```

```html
<div class="contrast-boost">
  <img src="card-art.jpg" alt="Higher contrast media">
</div>
```

## Best Practices

- Use small contrast adjustments first before reaching for stronger values
- Test both light and dark contexts because contrast changes feel different in each
- Avoid over-processing UI imagery that already has strong tonal separation
- Combine with brightness intentionally when refining hero or card media
