## Overview

Brightness filters help dim or lift media without changing the source asset, but CSS `filter` is not currently mapped by the Skelementor importer and no bundled brightness utility classes are shipped in `skelementor-utilities.css`.

Use native Elementor controls when possible, or apply brightness with custom frontend CSS when a true CSS filter is required.

## Example

```css
.media-dim {
  filter: brightness(0.75);
}

.media-boost {
  filter: brightness(1.1);
}
```

```html
<img alt="Dimmed image" class="media-dim" src="banner.jpg"/>
```

## Best Practices

- Reduce brightness for background media behind text
- Increase brightness sparingly to avoid washed-out visuals
- Pair brightness with contrast carefully so images stay readable
- Prefer opacity alone when you only need a simple dimming effect
