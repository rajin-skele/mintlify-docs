## Direction Utilities

| Class | CSS |
| ----- | --- |
| `.flex-row` | `flex-direction: row;` |
| `.flex-col` | `flex-direction: column;` |
| `.flex-row-reverse` | `flex-direction: row-reverse;` |
| `.flex-col-reverse` | `flex-direction: column-reverse;` |

```html
<div class="flex flex-row gap-4">
  <div class="p-4 bg-blue text-white rounded">Item 1</div>
  <div class="p-4 bg-blue text-white rounded">Item 2</div>
  <div class="p-4 bg-blue text-white rounded">Item 3</div>
</div>
```

## Responsive Structure

Use the responsive suffix system for structural shifts:

```html
<div class="flex flex-row flex-col--on-m gap-4">
  <div class="w-1-2"><div class="card">Item 1</div></div>
  <div class="w-1-2"><div class="card">Item 2</div></div>
</div>
```
