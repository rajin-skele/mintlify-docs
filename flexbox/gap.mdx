## Overview

Control spacing between flex items with the bundled gap utilities. Use the core `gap-*` family for symmetrical spacing, then reach for `gap-x-*` or `gap-y-*` when rows and columns need different values.

## Core Gap Utilities

| Class | Value | CSS |
| ----- | ----- | --- |
| `.gap-px` | 1px | `gap: 1px;` |
| `.gap-1` | 4px | `gap: var(--space-1);` |
| `.gap-2` | 8px | `gap: var(--space-2);` |
| `.gap-3` | 12px | `gap: var(--space-3);` |
| `.gap-4` | 16px | `gap: var(--space-4);` |
| `.gap-6` | 24px | `gap: var(--space-6);` |
| `.gap-8` | 32px | `gap: var(--space-8);` |
| `.gap-10` through `.gap-24` | 40px → 96px | Extended bundled scale |

## Axis Gap Utilities

- Column gap: `.gap-x-px`, `.gap-x-1` through `.gap-x-24`
- Row gap: `.gap-y-px`, `.gap-y-1` through `.gap-y-24`

```html
<div class="flex flex-wrap gap-6">
  <div class="w-1-3">
    <div class="card">Card 1</div>
  </div>
  <div class="w-1-3">
    <div class="card">Card 2</div>
  </div>
  <div class="w-1-3">
    <div class="card">Card 3</div>
  </div>
</div>
```

```html
<div class="flex flex-wrap gap-x-6 gap-y-4">
  <div class="w-1-2 p-4 bg-gray-light rounded">Column A</div>
  <div class="w-1-2 p-4 bg-gray-light rounded">Column B</div>
  <div class="w-1-2 p-4 bg-gray-light rounded">Column C</div>
  <div class="w-1-2 p-4 bg-gray-light rounded">Column D</div>
</div>
```

## Best Practices

- Use `gap-*` instead of margin for spacing between flex children.
- Use the same gap value across related components to keep rhythm consistent.
- Use `gap-x-*` and `gap-y-*` when wrapped rows need different horizontal and vertical spacing.
- Keep gap decisions in the container so child components stay reusable.
