## Order And Flex Behavior

- `.order-first`, `.order-last`
- `.flex-grow`, `.flex-shrink`

```html
<div class="flex items-center justify-between gap-4">
  <div class="p-4 bg-blue text-white rounded">Left</div>
  <div class="p-4 bg-gray-light rounded">Center</div>
  <div class="p-4 bg-green text-white rounded">Right</div>
</div>
```

```html
<div class="flex gap-4">
  <div class="p-4 bg-blue text-white rounded order-last">Moves last</div>
  <div class="p-4 bg-gray-light rounded">Stays in flow</div>
  <div class="p-4 bg-green text-white rounded order-first">Moves first</div>
</div>
```
