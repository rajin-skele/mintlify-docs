## Overview

Wrap utilities decide whether flex items stay in a single row or flow onto additional lines. They are especially useful for card collections, tag lists, and horizontally scrollable rails.

## Flex Wrap Utilities

| Class | Behavior | CSS | Usage |
| ----- | -------- | --- | ----- |
| `.flex-wrap` | Wrap | `flex-wrap: wrap;` | Let items move to new rows |
| `.flex-nowrap` | No wrap | `flex-wrap: nowrap;` | Keep items on one line |
| `.flex-wrap-reverse` | Wrap reverse | `flex-wrap: wrap-reverse;` | Reverse row stacking |

## Examples

### Wrapped Card Row

```html
<div class="flex flex-wrap gap-6">
  <div class="w-1-3">
    <div class="card p-6">Card 1</div>
  </div>
  <div class="w-1-3">
    <div class="card p-6">Card 2</div>
  </div>
  <div class="w-1-3">
    <div class="card p-6">Card 3</div>
  </div>
  <div class="w-1-3">
    <div class="card p-6">Card 4</div>
  </div>
</div>
```

### No-Wrap Rail

```html
<div class="flex flex-nowrap gap-4 overflow-auto">
  <div style="width: 12rem;" class="p-6 bg-gray-light rounded">Item 1</div>
  <div style="width: 12rem;" class="p-6 bg-gray-light rounded">Item 2</div>
  <div style="width: 12rem;" class="p-6 bg-gray-light rounded">Item 3</div>
  <div style="width: 12rem;" class="p-6 bg-gray-light rounded">Item 4</div>
</div>
```

### Reverse Wrap

```html
<div class="flex flex-wrap-reverse gap-4">
  <div class="w-1-3 p-4 bg-blue text-white rounded">Item 1</div>
  <div class="w-1-3 p-4 bg-green text-white rounded">Item 2</div>
  <div class="w-1-3 p-4 bg-red text-white rounded">Item 3</div>
  <div class="w-1-3 p-4 bg-yellow text-black rounded">Item 4</div>
</div>
```

## Best Practices

- Use `.flex-wrap` for dense UI rows that should gracefully move onto another line.
- Use `.flex-nowrap` for carousels, rails, and compact navigation.
- Pair wrap behavior with `gap-*` so spacing stays consistent across rows.
- Use the responsive suffix system when wrapping should only change at specific breakpoints, such as `flex-wrap--on-m`.
