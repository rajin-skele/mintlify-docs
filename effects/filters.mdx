## Overview

CSS filter effects like blur, brightness, contrast, grayscale, and drop-shadow are useful for media treatments and layered UI, but they are not currently mapped by the Skelementor importer in the same way as bundled utility classes or supported custom `box-shadow` values.

The filters docs now live in the dedicated `Filters` section:

- [Blur](/filters/blur)
- [Brightness](/filters/brightness)
- [Contrast](/filters/contrast)
- [Drop Shadow](/filters/drop-shadow)

Use those pages for filter-specific guidance and current limitations.
