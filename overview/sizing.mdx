## Overview

Control element dimensions with the bundled width, height, min-height, and max-width helpers. Fractional widths and screen-height utilities stay fixed, while `max-w-*` uses the bundled responsive scale.

## Quick Start

### Basic Sizing

```html
<!-- Width utilities -->
<div class="w-full p-4">Full width</div>
<div class="w-1-2 p-4">Half width</div>
<div class="w-1-3 p-4">One third width</div>

<!-- Height utilities -->
<div class="h-screen flex items-center justify-center">
  <div class="text-center">Full viewport height</div>
</div>

<!-- Max width utilities -->
<div class="max-w-2xl mx-auto p-6">
  <h1 class="text-3xl font-bold">Centered content</h1>
</div>
```

## Sizing Utilities Reference

### Width Utilities
- **Full:** `.w-full` (100%)
- **Auto:** `.w-auto`
- **Fractions:** `.w-1-2`, `.w-1-3`, `.w-2-3`, `.w-1-4`, `.w-3-4`

### Height Utilities
- **Full:** `.h-full` (100%)
- **Auto:** `.h-auto`
- **Screen:** `.h-screen` (100vh)

### Min Height Utilities
- **Screen:** `.min-h-screen` (100vh)
- **Full:** `.min-h-full` (100%)

### Max Width Utilities
- **Responsive bundle:** `.max-w-sm`, `.max-w-md`, `.max-w-lg`, `.max-w-xl`, `.max-w-2xl`, `.max-w-full`
