## Overview

Skelementor documents filters as custom CSS guidance rather than bundled utility classes. Use these pages when you want to import your own `filter`-based utilities and understand the current parser limitations before you do.

## Current Framework Truth

- `filter` is not currently mapped as a shipped Skelementor utility family
- These docs are for custom imported utilities and recommended patterns
- Use `box-shadow` docs separately when you want importer-supported shadow utilities
