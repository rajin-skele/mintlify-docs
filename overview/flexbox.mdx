## Overview

Use the bundled flexbox classes to control layout direction, wrapping, alignment, gap, visual order, and flexible growth. The same structural surface is also available through the `--on-*` responsive suffix system.

## Quick Start

### Basic Flexbox

```html
<!-- Horizontal layout -->
<div class="flex items-center justify-between p-6">
  <h1 class="text-2xl font-bold">
    Logo
  </h1>
  <nav class="flex gap-6">
    <a href="#">
      Home
    </a>
    <a href="#">
      About
    </a>
  </nav>
</div>
<!-- Centered content -->
<div class="flex items-center justify-center min-h-screen">
  <div class="text-center">
    <h1 class="text-4xl font-bold mb-4">
      Welcome
    </h1>
    <button class="btn btn-blue">
      Get Started
    </button>
  </div>
</div>
```

## Common Patterns

- **Headers:** Use `justify-between` for logo and navigation
- **Centered Content:** Combine `items-center` and `justify-center`
- **Card Grids:** Use `flex-wrap` with gap utilities
- **Form Layouts:** Stack form fields with `flex-col`
- **Responsive structure:** Switch structural behavior with helpers like `.flex-col--on-m` or `.items-center--on-xl`
