## Overview

The framework ships a semantic color layer for text, backgrounds, and borders. The goal is a small, dependable palette that works across editorial content, UI surfaces, and status messaging.

### Core Reference

| Color | Hex Value | Usage |
| ----- | --------- | ----- |
| White | `#ffffff` | Backgrounds, text on dark |
| Black | `#000000` | Text, borders |
| Dark Gray | `#374151` | Primary supporting text |
| Gray | `#6b7280` | Secondary text and borders |
| Light Gray | `#9ca3af` | Muted text |
| Blue | `#3b82f6` | Primary actions and accents |
| Green | `#10b981` | Success states |
| Red | `#ef4444` | Error states |
| Yellow | `#f59e0b` | Warning states |

## Quick Start

```html
<h1 class="text-black">
  Primary Heading
</h1>
<p class="text-gray">
  Secondary text
</p>
<a class="text-blue underline" href="#">
  Link
</a>
<div class="bg-white p-6 rounded-lg">
  White background
</div>
<div class="bg-blue text-white p-6 rounded-lg">
  Blue background
</div>
<div class="border-1 border-solid border-gray p-4 rounded">
  Gray border
</div>
```

## Accessibility

<Warning>
Ensure text and interface colors preserve readable contrast. The palette is designed for sensible defaults, but context still matters.
</Warning>
