## Get Started in 3 Steps

Use this page when you want the fastest route from plugin install to working classes inside Elementor.

<Card title="View Detailed Guide" icon="book-open" href="/getting-started/quickstart" horizontal>
  Need the longer walkthrough? Open the full quickstart guide.
</Card>

### Step 1: Install the Plugin

<Steps>
  <Step title="Get the package">
    Download the ZIP provided by your team, deployment bundle, or internal release channel.
  </Step>
  <Step title="Upload to WordPress">
    Go to **Plugins -> Add New -> Upload Plugin** in WordPress admin and select the ZIP file.
  </Step>
  <Step title="Activate">
    Activate the plugin after installation finishes.
  </Step>
</Steps>

<Info>
  **Requirements:** WordPress 5.8+, PHP 7.4+, and Elementor v4 with Atomic Elements enabled.
</Info>

### Step 2: Import Your First CSS

<Steps>
  <Step title="Open the importer">
    Open the plugin's importer admin screen from the WordPress dashboard.
  </Step>
  <Step title="Copy the bundled framework">
    Open the bundled utility stylesheet inside the plugin package and copy the CSS.
  </Step>
  <Step title="Paste and import">
    Paste the CSS into the importer textarea and run the import.
  </Step>
  <Step title="Confirm the result">
    Wait for the success state, then confirm the classes appear in Elementor.
  </Step>
</Steps>

### Step 3: Use Classes in Elementor

<Steps>
  <Step title="Open Elementor">
    Edit any page or post with Elementor.
  </Step>
  <Step title="Add an atomic element">
    Add a Heading, Text, Div Block, or another v4 atomic element.
  </Step>
  <Step title="Apply classes">
    Add utility classes in the element settings where Elementor exposes CSS classes.
  </Step>
  <Step title="Verify styling">
    Check the live preview to confirm the imported classes are applied.
  </Step>
</Steps>

```html
    <a class="text-base text-gray">About</a>
  </nav>
```

