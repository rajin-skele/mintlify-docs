## Overview

Radius utilities shape corners across buttons, cards, fields, and media. They work with border width, style, and color utilities, but can also be used on borderless surfaces.

## Border Radius Utilities

| Class | Value | CSS | Usage |
| ----- | ----- | --- | ----- |
| `.rounded-none` | 0 | `border-radius: 0;` | Square corners |
| `.rounded-sm` | 4px | `border-radius: 4px;` | Tight rounding |
| `.rounded` | 6px | `border-radius: 6px;` | Standard rounding |
| `.rounded-lg` | 8px | `border-radius: 8px;` | Comfortable card radius |
| `.rounded-xl` | 12px | `border-radius: 12px;` | Soft, modern surfaces |
| `.rounded-2xl` | 16px | `border-radius: 16px;` | Display containers |
| `.rounded-full` | 9999px | `border-radius: 9999px;` | Pills and circles |

## Examples

```html
<div class="border-2 border-solid border-gray rounded-none p-4">
  Square corners
</div>
<div class="border-2 border-solid border-gray rounded-sm p-4">
  Small rounding
</div>
<div class="border-2 border-solid border-gray rounded p-4">
  Standard rounding
</div>
<div class="border-2 border-solid border-gray rounded-lg p-4">
  Large rounding
</div>
<div class="border-2 border-solid border-gray rounded-xl p-4">
  Extra large rounding
</div>
<div class="border-2 border-solid border-gray rounded-full p-4">
  Fully rounded
</div>
```

```html
<input class="w-full p-3 border-1 border-solid border-gray rounded" placeholder="Rounded input" type="text"/>
<input class="w-full p-3 border-1 border-solid border-gray rounded-lg" placeholder="Large radius input" type="text"/>
```

```html
<div class="overflow-hidden rounded-full" style="width: 4rem; height: 4rem;">
  <img alt="Avatar" class="w-full h-full object-cover" src="avatar.jpg"/>
</div>
```

## Best Practices

- Use one or two radius sizes across a page so surfaces feel related.
- `rounded` and `rounded-lg` cover most interface needs.
- Reach for `rounded-full` on pills, avatars, and circular badges.
- Pair larger radius values with generous padding so corners feel intentional.
