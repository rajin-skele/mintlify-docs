## Get Started in 3 Steps

This is the longer version of the quickstart flow for teams that want a little more setup detail.

### Step 1: Install the Plugin

<AccordionGroup>
  <Accordion icon="download" title="Install the package">
    <Steps>
      <Step title="Get the build">
        Download the plugin ZIP from the release source or handoff package used by your team.
      </Step>
      <Step title="Upload to WordPress">
        In WordPress admin, go to **Plugins -> Add New -> Upload Plugin** and select the ZIP file.
      </Step>
      <Step title="Activate">
        Activate the plugin after installation completes.
      </Step>
    </Steps>
  </Accordion>
  <Accordion icon="check-circle" title="Verify requirements">
    Make sure your environment has WordPress 5.8+, PHP 7.4+, and Elementor v4 with Atomic Elements enabled.
    <Tip>
      If you plan to import design tokens, enable Elementor Variables too.
    </Tip>
  </Accordion>
</AccordionGroup>

### Step 2: Import Your First CSS

<AccordionGroup>
  <Accordion icon="code" title="Use the bundled framework">
    Start with the bundled utility CSS so you can verify the full workflow first.
    <Steps>
      <Step title="Open the importer admin screen">
        Open the plugin's importer screen from the WordPress dashboard.
      </Step>
      <Step title="Copy the bundled stylesheet">
        Copy the CSS from the utility stylesheet shipped with the plugin package.
      </Step>
      <Step title="Run the import">
        Paste the CSS into the importer and submit it.
      </Step>
      <Step title="Confirm success">
        Wait for the confirmation state, then check the imported classes inside Elementor.
      </Step>
    </Steps>
  </Accordion>
  <Accordion icon="pen-to-square" title="Import custom CSS">
    Once the starter import works, begin bringing in your own classes.
    <Steps>
      <Step title="Prepare the CSS">
        Follow the [CSS writing guidelines](/css-reference/writing-css) so your classes use supported properties and values.
      </Step>
      <Step title="Import in batches">
        For larger sets, import smaller groups first so you can isolate failures quickly.
      </Step>
      <Step title="Verify in Elementor">
        Test the imported classes in the editor before moving on to the next batch.
      </Step>
    </Steps>
  </Accordion>
</AccordionGroup>

### Step 3: Use Classes in Elementor

<Accordion icon="magic-wand" title="Apply utility classes">
  After import, utility classes are ready to use on Elementor v4 atomic elements.
  <Steps>
    <Step title="Open Elementor">
      Edit any page or post with Elementor.
    </Step>
    <Step title="Choose an atomic element">
      Add a Heading, Text, Div Block, Button, or another supported v4 element.
    </Step>
    <Step title="Assign classes">
      Add utility classes in Elementor's class field for that element.
    </Step>
    <Step title="Review the output">
      Confirm the imported styles render as expected in the editor preview.
    </Step>
  </Steps>
</Accordion>

## Common Issues

<Warning>
  **Important:** Avoid importing the same classes repeatedly without cleaning up or replacing the earlier set.
</Warning>

### Classes Not Working?

- Check that Elementor v4 Atomic Elements is enabled.
- Verify the import completed successfully in the importer admin screen.
- Clear Elementor cache through **Elementor -> Tools -> Regenerate CSS**.

### Import Errors?

- Reduce batch size to isolate the failing classes.
- Check for missing semicolons, unsupported values, or reserved class names.
- Confirm you are not importing duplicates that already exist.
