description: "Use the bundled framework consistently without drifting into unsupported patterns."
---

## Core Principles

- Use the bundled class names exactly as they ship.
- Prefer small, composable groups of classes over one-off custom patterns.
- Reach for `.btn`, `.card`, and `.cont` when the preset already fits the job.
- Keep layout changes structural and use the `--on-*` suffix system when responsiveness is needed.

## Good Composition

```html
<div class="card">
  <h3 class="text-xl font-semibold text-black mb-4">Title</h3>
  <p class="text-base leading-relaxed text-gray-dark mb-6">Content</p>
  <button class="btn btn-blue">Action</button>
</div>
```

## Responsive Guidance

```html
<div class="flex flex-row flex-col--on-m gap-6">
  <div class="w-1-2"><div class="card">Content</div></div>
  <div class="w-1-2"><div class="card">Content</div></div>
</div>
```

## Avoid

- Copying Tailwind-style prefixes like `md:` or `lg:`
- Reaching for class names that are not in the shipped Skelementor bundle
- Mixing margin-based spacing inside flex layouts when `gap-*` would do the job
- Using too many different spacing or type steps in the same component
