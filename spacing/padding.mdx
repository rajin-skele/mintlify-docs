## Overview

Use padding utilities to control space inside an element. The bundled `p-*`, `px-*`, `py-*`, `pt-*`, and `pb-*` families follow the shared Skelementor spacing scale.

## Scale

- Available values: `0`, `px`, `1`, `2`, `3`, `4`, `6`, `8`, `12`
- Families: `p-*`, `px-*`, `py-*`, `pt-*`, `pb-*`

```html
<div class="card p-8">
  <p class="text-sm uppercase tracking-wide text-gray mb-2">
    Bundled padding
  </p>
  <h3 class="text-2xl font-semibold text-black mb-4">
    Internal spacing stays consistent
  </h3>
  <p class="text-base leading-relaxed text-gray-dark">
    Start with `p-4` or `p-6` for most components, then increase to `p-8` or `p-12` for roomy sections.
  </p>
</div>
```

## Best Practices

- Use `p-*` for even padding on all sides.
- Use `px-*` and `py-*` when horizontal and vertical rhythm should differ.
- Use `pt-*` and `pb-*` for stacked sections or framed cards.
- Keep component padding values consistent across the same UI family.
