## Overview

Gap is the default way to space direct children inside flex layouts. The framework ships one gap system:

- `gap-*` for both axes
- `gap-x-*` for horizontal spacing
- `gap-y-*` for vertical spacing

<Tip>
Use gap when the space belongs to the parent-child relationship, and reserve margin for spacing outside the element itself.
</Tip>

## Common Usage

```html
<div class="flex gap-4">
  <div class="p-3 bg-blue text-white rounded">Item 1</div>
  <div class="p-3 bg-green text-white rounded">Item 2</div>
  <div class="p-3 bg-red text-white rounded">Item 3</div>
</div>
```

## Axis-Specific Gap

Use `gap-x-*` and `gap-y-*` when horizontal and vertical spacing need different values.

```html
<div class="flex flex-wrap gap-x-6 gap-y-3">
  <span class="px-3 py-1 bg-gray-light rounded-full">Design</span>
  <span class="px-3 py-1 bg-gray-light rounded-full">Systems</span>
  <span class="px-3 py-1 bg-gray-light rounded-full">Layout</span>
  <span class="px-3 py-1 bg-gray-light rounded-full">Docs</span>
</div>
```

## Patterns

### Navigation with Gap

```html
<nav class="flex items-center gap-6">
  <a href="#" class="text-gray">Home</a>
  <a href="#" class="text-gray">About</a>
  <a href="#" class="text-gray">Contact</a>
</nav>
```

### Card Grid with Gap

```html
<div class="flex flex-wrap gap-6">
  <div class="w-1-3">
    <div class="card p-6">Card 1</div>
  </div>
  <div class="w-1-3">
    <div class="card p-6">Card 2</div>
  </div>
  <div class="w-1-3">
    <div class="card p-6">Card 3</div>
  </div>
</div>
```

### Button Group with Gap

```html
<div class="flex gap-4">
  <button class="btn btn-blue">Primary</button>
  <button class="btn bg-gray text-white">Secondary</button>
  <button class="btn bg-gray-light text-gray">Tertiary</button>
</div>
```

### Form Fields with Gap

```html
<form class="flex flex-col gap-4 max-w-md">
  <input type="text" class="p-3 border-1 border-solid border-gray rounded" placeholder="Name">
  <input type="email" class="p-3 border-1 border-solid border-gray rounded" placeholder="Email">
  <button class="btn btn-blue">Submit</button>
</form>
```

## Best Practices

<Steps>
  <Step title="Use Gap for Container Spacing">
    Gap keeps spacing logic on the parent, which is easier to scan and maintain than child margins.
  </Step>
  <Step title="Reach for Axis Helpers Intentionally">
    Use `gap-x-*` and `gap-y-*` only when the layout truly needs separate horizontal and vertical spacing.
  </Step>
  <Step title="Keep the Scale Consistent">
    Reuse the bundled spacing tokens across sections, cards, forms, and navigation so layouts feel related.
  </Step>
  <Step title="Pair with Flex Wrap">
    Gap works especially well with `.flex-wrap` because spacing stays consistent as items move to new rows.
  </Step>
</Steps>

## Gap vs Margin

### When to Use Gap

- Spacing between flex items
- Tag lists and button groups
- Card rows and wrapped content
- Navigation items

### When to Use Margin

- Space outside an element
- Section separation
- Alignment helpers like `mx-auto`
- Negative spacing techniques
