## Overview

Use margin utilities to control space outside an element. The bundled `m-*`, `mx-*`, `my-*`, `mt-*`, `mb-*`, `ml-*`, and `mr-*` families use the shared framework spacing scale. Zero, pixel, auto, and negative helpers remain available for precise layout control.

## Scale

- Core values: `0`, `px`, `1`, `2`, `3`, `4`, `6`, `8`, `12`
- Auto helpers: `m-auto`, `mx-auto`, `my-auto`, `ml-auto`, `mr-auto`
- Negative helpers: `-m-*`, `-mx-*`, `-my-*`, `-mt-*`, `-mb-*`, `-ml-*`, `-mr-*`

```html
<section class="mt-12 mb-8">
  <h2 class="text-3xl font-bold mb-4">Section title</h2>
  <p class="text-base text-gray-dark mb-6">Use margin to separate blocks in the document flow.</p>
  <button class="btn btn-blue mr-4">Primary</button>
  <button class="btn btn-green">Secondary</button>
</section>
```

## Best Practices

- Use margin for spacing between sibling blocks.
- Use `mx-auto` to center constrained content.
- Use negative margin sparingly to create overlap or to compensate for container padding.
- Use gap instead of margin for spacing between flex children.
