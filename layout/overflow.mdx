## Overview

Use overflow utilities when content needs to be clipped or made scrollable inside a known frame. The bundle ships two utilities: `overflow-hidden` and `overflow-auto`.

## Overflow Utilities

| Class | Type | CSS | Usage |
| ----- | ---- | --- | ----- |
| `.overflow-hidden` | Hidden | `overflow: hidden;` | Clip overflowing content |
| `.overflow-auto` | Auto | `overflow: auto;` | Scroll only when needed |

## Examples

### Hidden Overflow

```html
<div class="overflow-hidden border-1 border-solid border-gray rounded" style="width: 18rem; height: 8rem;">
  <p class="p-4">
    This content might overflow the container and will be hidden if it does.
  </p>
</div>
```

### Auto Overflow

```html
<div class="overflow-auto border-1 border-solid border-gray rounded" style="width: 18rem; height: 8rem;">
  <p class="p-4">
    This content will show scrollbars when it overflows the container. You can
        scroll to see all the content.
  </p>
</div>
```

### Scrollable Content Panel

```html
<div class="max-w-2xl mx-auto">
  <div class="overflow-auto border-1 border-solid border-gray rounded-lg p-6" style="height: 24rem;">
    <h2 class="text-2xl font-bold mb-4">
      Scrollable Content
    </h2>
    <p class="mb-4">
      Long content that can scroll...
    </p>
    <p class="mb-4">
      More content...
    </p>
    <p class="mb-4">
      Additional content that causes scrolling...
    </p>
  </div>
</div>
```

### Image Cropping

```html
<div class="w-full overflow-hidden rounded-lg" style="height: 16rem;">
  <img alt="Cover image" class="w-full h-full object-cover" src="image.jpg"/>
</div>
```

### Modal Body

```html
<div class="fixed z-50 flex items-center justify-center" style="top: 0; right: 0; bottom: 0; left: 0;">
  <div class="bg-white rounded-lg max-w-md w-full mx-4 overflow-auto" style="max-height: 24rem;">
    <div class="p-6">
      <h3 class="text-xl font-semibold mb-4">
        Modal Title
      </h3>
      <p class="mb-4">
        Modal content that might be long...
      </p>
      <p class="mb-4">
        More content...
      </p>
      <p class="mb-4">
        More content...
      </p>
    </div>
  </div>
</div>
```

## Best Practices

<Steps>
  <Step title="Use Hidden for Cropped Surfaces">
    `overflow-hidden` is ideal for rounded media cards, avatars, and framed layouts.
  </Step>
  <Step title="Use Auto for Accessible Long Content">
    `overflow-auto` keeps content reachable without forcing scrollbars when they are not needed.
  </Step>
  <Step title="Give the Container a Real Frame">
    Overflow only becomes visible when the element has constrained size through height, width, or aspect ratio.
  </Step>
  <Step title="Pair With Object Fit">
    Overflow and object-fit work especially well together for media-heavy layouts.
  </Step>
</Steps>
