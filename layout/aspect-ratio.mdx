## Overview

Use aspect ratio utilities when the shape of the frame matters more than the media inside it. The framework ships `aspect-square` and `aspect-video`.

## Aspect Ratio Utilities

| Class | Ratio | CSS | Usage |
| ----- | ----- | --- | ----- |
| `.aspect-square` | 1:1 | `aspect-ratio: 1 / 1;` | Square frames |
| `.aspect-video` | 16:9 | `aspect-ratio: 16 / 9;` | Video and hero media |

## Examples

### Square Frame

```html
<div class="aspect-square bg-blue rounded" style="width: 12rem;">
</div>
```

### Square Avatar

```html
<div class="aspect-square overflow-hidden rounded-full" style="width: 8rem;">
  <img alt="Avatar" class="w-full h-full object-cover" src="avatar.jpg"/>
</div>
```

### Video Frame

```html
<div class="w-full aspect-video bg-black rounded-lg overflow-hidden">
  <iframe allowfullscreen="" class="w-full h-full" frameborder="0" src="https://www.youtube.com/embed/VIDEO_ID">
  </iframe>
</div>
```

### Mixed Media Row

```html
<div class="flex flex-wrap gap-4">
  <div class="aspect-square overflow-hidden rounded" style="width: 8rem;">
    <img alt="Thumbnail 1" class="w-full h-full object-cover" src="thumb1.jpg"/>
  </div>
  <div class="aspect-square overflow-hidden rounded" style="width: 8rem;">
    <img alt="Thumbnail 2" class="w-full h-full object-cover" src="thumb2.jpg"/>
  </div>
  <div class="aspect-video overflow-hidden rounded" style="width: 16rem;">
    <img alt="Video thumbnail" class="w-full h-full object-cover" src="video-thumb.jpg"/>
  </div>
</div>
```

### Video Hero

```html
<section class="w-full aspect-video relative overflow-hidden rounded-lg">
  <video autoplay="" class="w-full h-full object-cover" loop="" muted="">
    <source src="hero-video.mp4" type="video/mp4"/>
  </video>
  <div class="absolute bg-black opacity-50" style="top: 0; right: 0; bottom: 0; left: 0;">
  </div>
  <div class="absolute flex items-center justify-center" style="top: 0; right: 0; bottom: 0; left: 0;">
    <h1 class="text-4xl font-bold text-white">
      Hero Title
    </h1>
  </div>
</section>
```

## Best Practices

<Steps>
  <Step title="Set Width, Then Ratio">
    Aspect ratio controls shape, but width still determines the overall size.
  </Step>
  <Step title="Pair With Object Fit">
    Use `.object-cover` or `.object-contain` to decide how media behaves inside the frame.
  </Step>
  <Step title="Use Square for Repeating Media">
    Avatars, product tiles, and thumbnail systems often benefit from `aspect-square`.
  </Step>
  <Step title="Use Video for Editorial Surfaces">
    `aspect-video` works well for hero media, embeds, and featured content.
  </Step>
</Steps>
