## Overview

Use object-fit utilities on images or videos once the container has a known frame. The bundled framework ships two utilities: `object-cover` and `object-contain`.

## Object Fit Utilities

| Class | Type | CSS | Usage |
| ----- | ---- | --- | ----- |
| `.object-cover` | Cover | `object-fit: cover;` | Fill the frame, crop if needed |
| `.object-contain` | Contain | `object-fit: contain;` | Keep the whole asset visible |

## Object Cover

Use `.object-cover` when the frame matters more than seeing every edge of the image.

```html
<div class="overflow-hidden rounded" style="width: 18rem; height: 10rem;">
  <img alt="Cover image" class="w-full h-full object-cover" src="image.jpg"/>
</div>
```

## Object Contain

Use `.object-contain` when the whole image or logo needs to stay visible.

```html
<div class="border-1 border-solid border-gray rounded" style="width: 18rem; height: 10rem;">
  <img alt="Contain image" class="w-full h-full object-contain" src="image.jpg"/>
</div>
```

## Examples

### Card Media

```html
<div class="card overflow-hidden rounded-lg">
  <div class="overflow-hidden" style="height: 12rem;">
    <img alt="Card image" class="w-full h-full object-cover" src="hero.jpg"/>
  </div>
  <div class="p-6">
    <h3 class="text-xl font-semibold mb-2">
      Card Title
    </h3>
    <p class="text-gray">
      Card content
    </p>
  </div>
</div>
```

### Product Media

```html
<div class="bg-gray-light p-4 rounded" style="width: 18rem; height: 18rem;">
  <img alt="Product image" class="w-full h-full object-contain" src="product.jpg"/>
</div>
```

### Hero Image

```html
<section class="relative overflow-hidden rounded-lg" style="height: 24rem;">
  <img alt="Hero image" class="w-full h-full object-cover" src="hero.jpg"/>
  <div class="absolute bg-black opacity-50" style="top: 0; right: 0; bottom: 0; left: 0;">
  </div>
  <div class="absolute flex items-center justify-center" style="top: 0; right: 0; bottom: 0; left: 0;">
    <h1 class="text-4xl font-bold text-white">
      Hero Title
    </h1>
  </div>
</section>
```

## Best Practices

<Steps>
  <Step title="Set the Frame First">
    Object-fit only matters once the container has a known width, height, or aspect ratio.
  </Step>
  <Step title="Use Cover for Editorial Layouts">
    Card art, hero media, and gallery crops usually work best with `.object-cover`.
  </Step>
  <Step title="Use Contain for Product and Brand Assets">
    Logos and product images often need `.object-contain` so nothing important gets cropped.
  </Step>
  <Step title="Pair With Overflow Hidden">
    Cropped media looks cleaner when the container clips the edges.
  </Step>
</Steps>
