## What is Skelementor?

This documentation covers the Skelementor workflow for Elementor v4. Use it to install the Skelementor plugin, load the bundled Skelementor utility framework, and apply reusable classes and variables through Elementor's native Global Classes and Variables systems.

<Card title="Quick Start" icon="rocket" href="/quickstart" horizontal>
  Get from plugin install to first imported utilities in three steps.
</Card>

<Info>
  **Elementor v4 required:** Enable Atomic Elements, and turn on Variables if you want reusable design tokens. <Badge color="blue" size="sm">v4 Required</Badge>
</Info>

## Requirements

<Warning>
  **Compatibility:** Use Elementor v4 with Atomic Elements enabled. Turn on Variables as well if your workflow depends on imported design tokens.
</Warning>

| Requirement | Minimum | Recommended |
|------------|---------|-------------|
| **WordPress** | 5.8+ | 6.0+ |
| **PHP** | 7.4+ | 8.0+ |
| **Elementor** | v4 with Atomic Elements | Latest v4 build |
| **Variables** | Optional | Enabled |

## How It Works

<Steps>
  <Step title="Install & Activate">
    Install the Skelementor plugin in WordPress and confirm the Skelementor admin import screen loads.
  </Step>
  <Step title="Import CSS">
    Paste your utility CSS or the bundled Skelementor starter framework into the Skelementor import screen and run the import.
  </Step>
  <Step title="Use Classes & Variables">
    Apply imported classes and variables inside Elementor's atomic editor.
  </Step>
</Steps>

## Example Usage

Once imported, use utility classes directly in Elementor:

```html
<!-- Flexbox layout -->
<div class="flex items-center gap-4">
  <h1 class="text-2xl font-bold">Heading</h1>
  <p class="text-gray">Subtitle</p>
</div>

<!-- Button component -->
<button class="btn btn-blue">Click Me</button>

<!-- Card layout -->
<div class="card p-6 rounded-lg bg-white">
  <h2 class="text-xl font-semibold mb-4">Card Title</h2>
  <p class="text-gray">Card content goes here.</p>
</div>
```

## Why This Workflow Works

<Columns cols={2}>
  <div>
    <h3>Native editor integration</h3>
    <p>Classes and variables land inside Elementor's own systems, so they are easier to manage and reuse across the site.</p>
  </div>
  <div>
    <h3>CSS-first authoring</h3>
    <p>Write familiar CSS utilities, then map them into Elementor instead of rebuilding the same decisions manually in the editor.</p>
  </div>
  <div>
    <h3>Predictable utility scale</h3>
    <p>Skelementor keeps spacing, type, layout, and color decisions consistent across pages and components.</p>
  </div>
  <div>
    <h3>Flexible expansion</h3>
    <p>Start with the bundled Skelementor framework, then extend it with your own custom utilities and variables as your design system grows.</p>
  </div>
</Columns>
