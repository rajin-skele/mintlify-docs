## Text Scale

The bundled `text-*` classes are the framework's default font-size scale. These names already map to the responsive clamp-based values shipped in Skelementor.

| Class | Range | CSS |
| ----- | ----- | --- |
| `.text-2xs` | 9.3px → 10.2px | `clamp(0.58rem, calc(0.49rem + 0.09vw), 0.64rem)` |
| `.text-xs` | 11px → 12.8px | `clamp(0.69rem, calc(0.59rem + 0.16vw), 0.8rem)` |
| `.text-sm` | 13.3px → 16px | `clamp(0.83rem, calc(0.71rem + 0.25vw), 1rem)` |
| `.text-base` | 16px → 20px | `clamp(1rem, calc(0.85rem + 0.37vw), 1.25rem)` |

## Choosing Sizes

| Component | Recommended range |
| --------- | ----------------- |
| Labels and helper copy | `.text-2xs` to `.text-sm` |
| Body copy | `.text-base` to `.text-lg` |
| Card and section headings | `.text-xl` to `.text-3xl` |
| Hero headings | `.text-4xl` to `.text-7xl` |
| Oversized statements | `.text-8xl` to `.text-9xl` |

<Tip>
Pair `text-*` with `.leading-*` and `.font-*` utilities instead of looking for a separate naming scheme.
</Tip>
