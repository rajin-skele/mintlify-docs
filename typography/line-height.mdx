## Leading Scale

The bundled leading classes are the framework defaults. Each one uses the shipped clamp-based value and is designed to pair cleanly with the bundled `text-*` scale.

| Class | CSS | Best for |
| ----- | --- | -------- |
| `.leading-tight` | `clamp(1, calc(0.85 + 0.37vw), 1.25)` | Compact headings and stacked titles |
| `.leading-normal` | `clamp(1.125, calc(0.96rem + 0.42vw), 1.41rem)` | Everyday body copy |
| `.leading-relaxed` | `clamp(1.5, calc(1.28rem + 0.56vw), 1.88rem)` | Long-form paragraphs |
| `.leading-loose` | `clamp(2, calc(1.71rem + 0.74vw), 2.5rem)` | Spacious display copy |

```html
<article class="max-w-lg mx-auto">
  <h2 class="text-3xl font-bold leading-tight text-black mb-4">
    Built-in rhythm for bundled typography
  </h2>
  <p class="text-base leading-relaxed text-gray-dark">
    Use `.leading-tight` when you want multi-line headings to stay compact. Swap to `.leading-relaxed` when paragraphs need more room to breathe.
  </p>
</article>
```

## Best Practices

- Use `.leading-tight` for headings and labels that should feel compact.
- Use `.leading-normal` for UI copy and shorter paragraphs.
- Use `.leading-relaxed` for body copy, summaries, and longer text blocks.
- Use `.leading-loose` sparingly for quotes and roomy display copy.
