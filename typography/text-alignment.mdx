## Alignment Utilities

The alignment utilities map directly to logical CSS properties, so they work automatically for both LTR and RTL content.

| Class | CSS | When to use |
| ----- | --- | ----------- |
| `.text-start` | `text-align: start;` | Default reading alignment |
| `.text-center` | `text-align: center;` | Headlines, testimonials, CTA sections |
| `.text-end` | `text-align: end;` | Metadata, side notes, number-heavy content |

```html
<div class="card">
  <header class="text-center mb-6">
    <p class="text-sm text-gray">
      Case study
    </p>
    <h2 class="text-4xl font-semibold text-black">
      Center alignment puts the spotlight on the message
    </h2>
  </header>
  <aside class="text-end text-sm text-gray">
    <p>
      Updated: April 2026
    </p>
    <p>
      Written by: project-team
    </p>
  </aside>
</div>
```

## Strategy

- Keep paragraphs at `.text-start` for readability.
- Combine `.text-center` with `.max-w-md mx-auto` when you want a centered content column.
- Use `.text-end` for side notes, meta information, and layouts that benefit from edge alignment.
- When alignment needs to shift across breakpoints, change the surrounding layout with the structural suffix system instead of looking for text-alignment suffix variants.
