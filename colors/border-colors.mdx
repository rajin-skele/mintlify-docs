## Overview

Border color utilities work with the bundled width, style, and radius helpers. The shipped palette is intentionally small: neutrals for structure and blue for emphasis.

## Border Color Utilities

| Class | Color | Hex | CSS | Usage |
| ----- | ----- | --- | --- | ----- |
| `.border-white` | White | `#ffffff` | `border-color: #ffffff;` | Borders on dark surfaces |
| `.border-black` | Black | `#000000` | `border-color: #000000;` | Strong framing |
| `.border-gray` | Gray | `#6b7280` | `border-color: #6b7280;` | Standard borders |
| `.border-gray-light` | Light gray | `#e5e7eb` | `border-color: #e5e7eb;` | Soft separation |
| `.border-blue` | Blue | `#3b82f6` | `border-color: #3b82f6;` | Accent borders |

## Examples

```html
<div class="border-1 border-solid border-gray p-4 rounded">Gray border</div>
<div class="border-1 border-solid border-gray-light p-4 rounded">Light gray border</div>
<div class="border-1 border-solid border-blue p-4 rounded">Blue border</div>
<div class="border-2 border-solid border-black p-4 rounded">Thick black border</div>
```

## Common Patterns

### Form Field

```html
<input
  type="text"
  class="w-full p-3 border-1 border-solid border-gray rounded"
  placeholder="Standard input"
>
```

### Accent Border

```html
<div
  class="bg-white p-6 rounded"
  style="border-left: 4px solid #3b82f6;"
>
  <h3 class="text-lg font-semibold mb-2">Accent Border</h3>
  <p class="text-gray">Use the bundled blue accent for emphasis.</p>
</div>
```

### Framed Card

```html
<div class="border-2 border-solid border-blue rounded-lg p-6 bg-white">
  <h3 class="text-xl font-semibold mb-4">Blue framed card</h3>
  <p class="text-gray">
    Pair border color with width and style utilities for complete border treatment.
  </p>
</div>
```

## Best Practices

- Use `border-gray-light` for soft separation in cards and panels.
- Use `border-gray` or `border-black` when structure needs to read clearly.
- Use `border-blue` as the single bundled accent border so emphasis stays meaningful.
- Always pair border color with an explicit width and style, such as `border-1 border-solid border-gray`.
