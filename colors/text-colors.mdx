## Overview

Text color utilities provide the framework's semantic foreground palette. They cover primary reading colors, accent links, and common status tones.

## Text Color Utilities

| Class | Color | Hex | CSS | Usage |
| ----- | ----- | --- | --- | ----- |
| `.text-white` | White | `#ffffff` | `color: #ffffff;` | Text on dark surfaces |
| `.text-black` | Black | `#000000` | `color: #000000;` | Primary text |
| `.text-gray-dark` | Dark gray | `#374151` | `color: #374151;` | Strong supporting text |
| `.text-gray` | Gray | `#6b7280` | `color: #6b7280;` | Secondary text |
| `.text-gray-light` | Light gray | `#9ca3af` | `color: #9ca3af;` | Muted text |
| `.text-blue` | Blue | `#3b82f6` | `color: #3b82f6;` | Links and emphasis |
| `.text-green` | Green | `#10b981` | `color: #10b981;` | Success states |
| `.text-red` | Red | `#ef4444` | `color: #ef4444;` | Error states |
| `.text-yellow` | Yellow | `#f59e0b` | `color: #f59e0b;` | Warning states |

## Examples

```html
<h1 class="text-3xl font-bold text-black">Primary Heading</h1>
<p class="text-base text-gray">Secondary text content</p>
<a href="#" class="text-blue underline">Link text</a>
<div class="text-green">Success message</div>
<div class="text-red">Error message</div>
<div class="text-yellow">Warning message</div>
```

## Common Patterns

### Heading Hierarchy

```html
<h1 class="text-4xl font-bold text-black">Main Heading</h1>
<h2 class="text-2xl font-semibold text-gray-dark">Section Heading</h2>
<p class="text-base text-gray">Body text content</p>
```

### Status Messaging

```html
<div class="text-green">Success: operation completed</div>
<div class="text-red">Error: something went wrong</div>
<div class="text-yellow">Warning: please review this</div>
```

### Contrast Combinations

```html
<div class="bg-black text-white p-6">Black background, white text</div>
<div class="bg-white text-black p-6 border-1 border-solid border-black">White background, black text</div>
<div class="bg-blue text-white p-6">Blue background, white text</div>
```

## Best Practices

- Use darker neutrals for long-form reading and lighter neutrals for supporting copy.
- Reserve color accents like blue, green, red, and yellow for meaning, not decoration alone.
- Check contrast whenever text sits on a colored background.
- Keep the status palette consistent so users learn what each color means.
