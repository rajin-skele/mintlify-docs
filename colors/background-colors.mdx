## Overview

Background color utilities define large surfaces and stateful UI containers. The palette is semantic and intentionally compact so sections, cards, and alerts stay visually coherent.

## Background Color Utilities

| Class | Color | Hex | CSS | Usage |
| ----- | ----- | --- | --- | ----- |
| `.bg-white` | White | `#ffffff` | `background-color: #ffffff;` | Default surfaces |
| `.bg-black` | Black | `#000000` | `background-color: #000000;` | High-contrast surfaces |
| `.bg-gray-dark` | Dark gray | `#374151` | `background-color: #374151;` | Dark sections |
| `.bg-gray` | Gray | `#6b7280` | `background-color: #6b7280;` | Neutral backgrounds |
| `.bg-gray-light` | Light gray | `#f3f4f6` | `background-color: #f3f4f6;` | Subtle section changes |
| `.bg-blue` | Blue | `#3b82f6` | `background-color: #3b82f6;` | Primary emphasis |
| `.bg-green` | Green | `#10b981` | `background-color: #10b981;` | Success states |
| `.bg-red` | Red | `#ef4444` | `background-color: #ef4444;` | Error states |
| `.bg-yellow` | Yellow | `#f59e0b` | `background-color: #f59e0b;` | Warning states |

## Examples

```html
<div class="bg-white p-6 rounded-lg">
  White background card
</div>
<div class="bg-gray-light p-6 rounded-lg">
  Light gray background
</div>
<div class="bg-blue text-white p-6 rounded-lg">
  Blue background with white text
</div>
<div class="bg-green text-white p-6 rounded-lg">
  Green success background
</div>
<div class="bg-red text-white p-6 rounded-lg">
  Red error background
</div>
```

## Common Patterns

### Alternating Sections

```html
<section class="bg-white py-12">
  <div class="cont">
    <h2 class="text-3xl font-bold mb-6">
      Section Title
    </h2>
    <p class="text-gray">
      Section content
    </p>
  </div>
</section>
<section class="bg-gray-light py-12">
  <div class="cont">
    <h2 class="text-3xl font-bold mb-6">
      Alternating Section
    </h2>
    <p class="text-gray">
      Alternating background
    </p>
  </div>
</section>
```

### Status Surfaces

```html
<div class="bg-green text-white p-4 rounded">
  Success: operation completed
</div>
<div class="bg-red text-white p-4 rounded">
  Error: something went wrong
</div>
<div class="bg-yellow text-black p-4 rounded">
  Warning: please check this
</div>
<div class="bg-blue text-white p-4 rounded">
  Info: additional information
</div>
```

### Accent Card

```html
<div class="bg-white p-6 rounded-lg" style="border-left: 4px solid #3b82f6;">
  <h3 class="text-xl font-semibold text-black mb-2">
    Card Title
  </h3>
  <p class="text-gray">
    Card content with blue accent border
  </p>
</div>
```

## Best Practices

- Use `bg-white` and `bg-gray-light` for most editorial and application surfaces.
- Reserve saturated backgrounds like blue, green, red, and yellow for purposeful emphasis.
- Pair colored backgrounds with matching readable text colors.
- Alternate subtle neutrals between sections to create rhythm without visual noise.
