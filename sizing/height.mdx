## Overview

Height utilities in the bundle focus on the common layout cases: follow content, fill a parent, or fill the viewport. For component-specific pixel heights, use custom CSS rather than expecting a large fixed-height utility scale.

## Height Utilities

| Class | Value | CSS | Usage |
| ----- | ----- | --- | ----- |
| `.h-full` | 100% | `height: 100%;` | Match the parent height |
| `.h-auto` | Auto | `height: auto;` | Follow content |
| `.h-screen` | 100vh | `height: 100vh;` | Fill the viewport |

## Min Height Utilities

| Class | Value | CSS | Usage |
| ----- | ----- | --- | ----- |
| `.min-h-screen` | 100vh | `min-height: 100vh;` | At least the full viewport |
| `.min-h-full` | 100% | `min-height: 100%;` | At least the parent height |

## Usage

### Full Height

```html
<div style="height: 22rem;" class="bg-gray-light rounded-lg p-4">
  <div class="h-full bg-white rounded p-4">
    Child panel that matches its parent height
  </div>
</div>
```

### Auto Height

```html
<div class="card h-auto p-6">
  <h3 class="text-xl font-semibold mb-4">Card Title</h3>
  <p class="text-gray">Content that determines height</p>
</div>
```

### Screen Height

```html
<section class="h-screen flex items-center justify-center bg-gray-light">
  <div class="text-center">
    <h1 class="text-5xl font-bold mb-4">Hero Title</h1>
    <p class="text-lg text-gray mb-8">Hero subtitle</p>
    <button class="btn btn-blue">Get Started</button>
  </div>
</section>
```

### Minimum Screen Height

```html
<main class="min-h-screen p-6">
  <h1 class="text-3xl font-bold mb-6">Page Title</h1>
  <p class="text-gray">Content that may be longer than the viewport.</p>
</main>
```

## Height Examples

### Full-Height Layout

```html
<div class="h-screen flex">
  <aside class="w-1-4 h-full p-6 bg-gray-light">
    <h2 class="text-lg font-semibold mb-4">Sidebar</h2>
    <nav class="flex flex-col gap-2">
      <a href="#" class="text-gray">Link 1</a>
      <a href="#" class="text-gray">Link 2</a>
    </nav>
  </aside>
  <main class="w-3-4 h-full p-6 overflow-auto">
    <h1 class="text-3xl font-bold mb-6">Main Content</h1>
    <p class="text-gray">Scrollable content</p>
  </main>
</div>
```

### Page with Minimum Height

```html
<div class="min-h-screen flex flex-col">
  <header
    class="p-6 bg-white"
    style="border-bottom: 1px solid #e5e7eb;"
  >
    <h1 class="text-2xl font-bold">Header</h1>
  </header>
  <main class="p-6">
    <h2 class="text-3xl font-bold mb-6">Content</h2>
    <p class="text-gray">Page content</p>
  </main>
  <footer class="p-6 bg-gray-light">
    <p class="text-gray">Footer</p>
  </footer>
</div>
```

## Best Practices

<Steps>
  <Step title="Use Screen Height for Full Views">
    Reach for `.h-screen` when a section or shell should fill the viewport exactly.
  </Step>
  <Step title="Use Min Height for Pages">
    `.min-h-screen` is usually a better page-level default because it allows content to grow naturally.
  </Step>
  <Step title="Use Parent Height Deliberately">
    `h-full` and `min-h-full` only work when a parent already establishes height.
  </Step>
  <Step title="Consider Overflow">
    Add `overflow-auto` or `overflow-hidden` when fixed vertical space and long content need controlled behavior.
  </Step>
</Steps>
