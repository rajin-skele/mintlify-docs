## Overview

Width utilities cover the core percentage-based widths used throughout the framework. They are intentionally simple: full width, auto width, and a small fractional set for common layouts.

## Width Utilities

| Class | Value | CSS | Usage |
| ----- | ----- | --- | ----- |
| `.w-full` | 100% | `width: 100%;` | Fill the available width |
| `.w-auto` | Auto | `width: auto;` | Size to content |
| `.w-1-2` | 50% | `width: 50%;` | Two-column layouts |
| `.w-1-3` | 33.333% | `width: 33.333%;` | Three-up layouts |
| `.w-2-3` | 66.666% | `width: 66.666%;` | Main content areas |
| `.w-1-4` | 25% | `width: 25%;` | Sidebars or metadata rails |
| `.w-3-4` | 75% | `width: 75%;` | Content-heavy panels |

## Full Width

Use `.w-full` when a field, card, or section should expand to the width of its parent.

```html
<input type="text" class="w-full p-3 border-1 border-solid border-gray rounded" placeholder="Enter text">
```

## Auto Width

Use `.w-auto` when content should define the width.

```html
<button class="w-auto px-6 py-3 bg-blue text-white rounded">
  Button Text
</button>
```

## Fractional Widths

Fractional width utilities are best for flex-based layouts.

```html
<div class="flex gap-6">
  <div class="w-1-2 p-6 bg-gray-light rounded">
    Half width
  </div>
  <div class="w-1-2 p-6 bg-white rounded">
    Half width
  </div>
</div>
```

## Width Examples

### Three-Column Grid

```html
<div class="flex flex-wrap gap-6">
  <div class="w-1-3 p-6 bg-gray-light rounded">
    <h3 class="text-lg font-semibold mb-2">Column 1</h3>
    <p class="text-gray">Content</p>
  </div>
  <div class="w-1-3 p-6 bg-gray-light rounded">
    <h3 class="text-lg font-semibold mb-2">Column 2</h3>
    <p class="text-gray">Content</p>
  </div>
  <div class="w-1-3 p-6 bg-gray-light rounded">
    <h3 class="text-lg font-semibold mb-2">Column 3</h3>
    <p class="text-gray">Content</p>
  </div>
</div>
```

### Sidebar Layout

```html
<div class="flex gap-6">
  <aside class="w-1-4 p-6 bg-gray-light rounded">
    <h2 class="text-lg font-semibold mb-4">Sidebar</h2>
    <nav class="flex flex-col gap-2">
      <a href="#" class="text-gray">Link 1</a>
      <a href="#" class="text-gray">Link 2</a>
    </nav>
  </aside>
  <main class="w-3-4 p-6 bg-white rounded">
    <h1 class="text-3xl font-bold mb-6">Main Content</h1>
    <p class="text-gray">Content goes here</p>
  </main>
</div>
```

### Full-Width Form

```html
<form class="max-w-md">
  <div class="mb-4">
    <label class="text-sm font-medium mb-2">Email</label>
    <input type="email" class="w-full p-3 border-1 border-solid border-gray rounded">
  </div>
  <div class="mb-4">
    <label class="text-sm font-medium mb-2">Message</label>
    <textarea class="w-full p-3 border-1 border-solid border-gray rounded" rows="4"></textarea>
  </div>
  <button class="w-full btn btn-blue">Submit</button>
</form>
```

## Best Practices

<Steps>
  <Step title="Use Full Width for Forms">
    `.w-full` keeps form controls predictable and aligned.
  </Step>
  <Step title="Use Fractions for Structure">
    Reach for `w-1-2`, `w-1-3`, and related helpers when the layout itself is column-based.
  </Step>
  <Step title="Pair With Flex Wrap">
    Width fractions work best with `.flex-wrap` so layouts can reflow instead of crushing content.
  </Step>
  <Step title="Constrain With Max Width">
    Use width utilities alongside `max-w-*` when content needs both expansion and readable limits.
  </Step>
</Steps>
