## One Framework

Skelementor ships one bundled utility framework for Elementor v4. The default class names are the framework. Where a class family uses responsive `clamp()` values, that responsive behavior is built in and does not need a separate naming layer.

Use [skelementor-utilities.css](/Users/rajin/Desktop/css-utility-importer/skelementor-utilities.css) as the source of truth for the shipped utilities.

## How The Bundle Is Shaped

- Default responsive families: `text-*`, `leading-*`, `m-*`, `p-*`, `gap-*`, `max-w-*`, `border-*`
- Intentionally fixed helpers: zero, auto, px, widths, heights, rounded utilities, color helpers, weights, tracking, display, positioning, and component presets
- Responsive structural suffixes: `--on-xxl`, `--on-xl`, `--on-l`, `--on-m`, `--on-s`, `--on-xs`
