## Overview

The bundled container preset is `.cont`. It centers content, applies the framework's max-width token, and adds horizontal padding.

<Note>
  `.cont` is used instead of `container` because `container` is reserved in Elementor.
</Note>

```html
<div class="cont">
  <h1 class="text-3xl font-bold text-black mb-6">Page Title</h1>
  <p class="text-lg text-gray">Centered content with the bundled container preset.</p>
</div>
```

## Typical Uses

- Page sections
- Marketing blocks
- Centered article wrappers
- Card grids that should not stretch full width

```html
<section class="my-12">
  <div class="cont">
    <div class="flex gap-6">
      <div class="w-1-2"><div class="card">Content 1</div></div>
      <div class="w-1-2"><div class="card">Content 2</div></div>
    </div>
  </div>
</section>
```
