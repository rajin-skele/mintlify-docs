## Overview

The bundled button preset gives you a stable baseline for calls to action. Start with `.btn`, then add a size and color variant when needed.

## Shipped Classes

- Base: `.btn`
- Sizes: `.btn-sm`, `.btn-lg`
- Colors: `.btn-blue`, `.btn-green`, `.btn-red`

```html
<button class="btn btn-blue">Primary Button</button>
<button class="btn btn-green btn-lg">Large Success Button</button>
<button class="btn btn-red btn-sm">Small Danger Button</button>
```

## Composition Patterns

```html
<div class="flex gap-4">
  <button class="btn btn-blue">Save</button>
  <button class="btn btn-green">Publish</button>
  <button class="btn btn-red">Delete</button>
</div>
```

```html
<button class="btn border-2 border-solid border-blue text-blue bg-white">
  Outlined Button
</button>
```

## Notes

- Keep `.btn` as the base whenever you want the bundled button proportions.
- Add utility classes on top when you need spacing or layout adjustments.
- Use color variants semantically: blue for primary, green for success, red for destructive actions.
