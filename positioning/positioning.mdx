## Position Types

Control how elements are positioned with position utilities.

| Class | Type | CSS | Usage |
| ----- | ---- | --- | ----- |
| `.static` | Static | `position: static;` | Default positioning |
| `.relative` | Relative | `position: relative;` | Position relative to normal flow |
| `.absolute` | Absolute | `position: absolute;` | Position relative to nearest positioned ancestor |
| `.fixed` | Fixed | `position: fixed;` | Position relative to viewport |
| `.sticky` | Sticky | `position: sticky;` | Sticky positioning |

### Examples

```html
<!-- Position examples -->
<div class="static p-4 bg-blue text-white">Static positioning (default)</div>
<div class="relative p-4 bg-green text-white">Relative positioning</div>

<div class="fixed p-4 bg-yellow text-black">Fixed positioning</div>
<div class="sticky p-4 bg-purple text-white">Sticky positioning</div>
```

## Common Positioning Patterns

### Overlay Elements

#### Image Overlay

```html
<div class="relative">
  <img src="image.jpg" class="w-full h-64 object-cover" alt="Background image">
  <div class="absolute inset-0 bg-black opacity-50"></div>
  <div class="absolute inset-0 flex items-center justify-center">
    <h2 class="text-white text-2xl font-bold">Overlay Text</h2>
  </div>
</div>
```

### Fixed Header

#### Fixed Navigation

```html
<header class="fixed top-0 left-0 right-0 z-50 bg-white border-b border-gray-light">
  <div class="flex items-center justify-between p-4">
    <h1 class="text-xl font-bold">Logo</h1>
    <nav class="flex gap-6">
      <a href="#" class="text-gray">Home</a>
      <a href="#" class="text-gray">About</a>
      <a href="#" class="text-gray">Contact</a>
    </nav>
  </div>
</header>
<main class="pt-16">
  <div class="p-6">
    <h2 class="text-2xl font-semibold mb-4">Main Content</h2>
    <p class="text-gray">Content goes here...</p>
  </div>
</main>
```

### Sticky Sidebar

#### Sticky Sidebar

```html
<div class="flex gap-6">
  <aside class="w-64 sticky top-0 h-screen overflow-y-auto">
    <div class="p-6 bg-gray-light">
      <h2 class="text-lg font-semibold mb-4">Sidebar</h2>
      <nav class="flex flex-col gap-2">
        <a href="#" class="text-gray">Link 1</a>
        <a href="#" class="text-gray">Link 2</a>
        <a href="#" class="text-gray">Link 3</a>
      </nav>
    </div>
  </aside>
  <main class="flex-1 p-6">
    <h1 class="text-3xl font-bold mb-6">Main Content</h1>
    <p class="text-gray mb-4">Content goes here...</p>
  </main>
</div>
```

### Modal Dialog

#### Modal Dialog

```html

  <!-- Backdrop -->
  <div class="absolute inset-0 bg-black opacity-50"></div>
  
  <!-- Modal -->
  <div class="relative bg-white rounded-lg p-6 max-w-md w-full mx-4">
    <h3 class="text-xl font-semibold mb-4">Modal Title</h3>
    <p class="text-gray mb-6">Modal content goes here.</p>
    <div class="flex gap-4 justify-end">
      <button class="btn bg-gray text-white">Cancel</button>
      <button class="btn btn-blue">Confirm</button>
    </div>
  </div>
</div>
```

## Positioning Best Practices

<Steps>
  <Step title="Choose the Right Position Type">
    Use `static` for normal flow, `relative` for offset positioning, `absolute` for positioning relative to ancestors, `fixed` for viewport positioning, and `sticky` for scroll-based positioning.
  </Step>
  <Step title="Plan Your Layout">
    Think about how positioning affects document flow and other elements before implementing.
  </Step>
  <Step title="Combine with Z-Index">
    Use z-index utilities to control stacking order when elements overlap. See the [Z-Index documentation](/layout/z-index) for details.
  </Step>
  <Step title="Test on Different Devices">
    Ensure positioning works correctly on mobile and desktop, especially for fixed and sticky elements.
  </Step>
</Steps>

### Performance Considerations

#### Performance Tips

- Use `position: fixed` sparingly as it can cause performance issues
- Avoid deeply nested positioned elements
- Test sticky positioning on different browsers
- Use `transform` instead of `position` for animations when possible
